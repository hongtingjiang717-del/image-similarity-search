为完整项目新增的工程文件：

- `common/paths.py`：相对项目的默认路径及环境变量。
- `common/engine.py`：训练/验证中的模式、梯度和损失汇总。
- `common/training.py`：命令行、数据划分与训练记录。
- `common/inference.py`、`predict.py`：Web 与命令行共用推理能力。
- `scripts/check_dataset.py`：标签与图片解码检查。
- `scripts/evaluate.py`：验证集损失，分类任务额外报告准确率。
- `tests/test_project.py`：临时数据上的训练、建库和 API 集成验证。
- README、依赖声明及 docs：运行与修正说明。

教材代码用于组织和对照；文档中的安装命令、服务器配置建议以及演示性操作没有作为自动执行指令。当前没有安装依赖或执行云端操作。
