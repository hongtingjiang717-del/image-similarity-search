# 面向初学者的注释补充说明

本次按照初学者阅读需要，为项目源码增加中文解释，保持原有程序逻辑。

## 覆盖范围

- 34 个 Python 文件：包括公共模块、三个模型任务、命令行推理、Flask 后端、检查脚本、测试和包初始化文件。
- 2 个历史 Notebook 中的 11 个代码单元：增加语法和实验上下文解释，保留单元顺序、已有输出、执行计数及其他元数据。
- HTML、CSS、JavaScript：解释页面元素、布局属性、事件绑定、异步请求、上传格式、响应字段与显示逻辑。
- 两个依赖文件：解释工具用途、版本范围、CPU 构建与依赖清单读取方式。
- 新增 `初学者阅读指南.md`，并在 README 增加学习入口。

## 注释怎样组织

文件开头说明职责、输入输出和上下游关系；函数前说明参数与返回值；关键语句前说明作用和语法。模型部分补充通道数、空间尺寸及批次维度的变化。训练部分解释梯度、损失、优化器、数据划分、最佳权重和日志。检索部分解释向量、归一化、真实文件名映射、模型指纹与数据库状态。

注释优先说明正在处理的数据和这一步的目的。`#` 开头的文字不参与执行；没有通过修改原有 docstring 来改变 `__doc__` 或命令行帮助。

Notebook 是历史学习实验，本次没有重跑其中的长轮数训练。旧实验中的平均损失分母、固定批次重塑以及变量命名问题已在注释中提示；实际修正后的正式入口仍是各包内的 Python 文件。
