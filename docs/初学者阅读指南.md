# 从零阅读智图寻宝代码

项目源码已加入中文教学注释：文件开头说明它在整个项目中的位置，函数前说明输入输出，关键语句前解释作用和语法。注释从“程序正在处理什么数据”出发阅读，不需要一次记住所有库函数。

## 先认识文件与程序

| 名词 | 可以怎样理解 | 本项目例子 |
|---|---|---|
| 文件/模块 | 一个 `.py` 文件是一组 Python 定义 | `denoising_model.py` 定义网络 |
| 包 | 把相关模块放在一个目录组织起来 | `image_denoising` |
| 第三方库 | 别人提供、安装后复用的工具 | PyTorch、Pillow、Flask |
| 函数 | 取一个名字的一组操作，调用时执行 | `build_transform()` |
| 参数 | 函数需要调用者提供的信息 | `get_device("cpu")` 中的 `"cpu"` |
| 返回值 | 函数完成后交回的结果 | `get_device` 返回设备对象 |
| 类 | 用来创建一类对象的模板 | `Classifier` |
| 对象/实例 | 根据类创建出来、可保存自己状态的实体 | `model = Classifier()` 中的 `model` |
| 方法 | 写在类里面、与对象或类关联的函数 | `model.forward(x)` |
| 属性 | 保存在对象里的数据 | `dataset.paths` |
| 异常 | 程序用来报告无法继续的情况 | 图片不存在时的 `FileNotFoundError` |

Python 根据缩进识别代码块。`if`、`for`、`def`、`class` 后面的冒号表示下面有一组缩进代码。一个函数内部的语句，通常只有调用这个函数才执行。

`#` 后面是注释，帮助人理解，不参与模型运算。三引号放在文件、函数或类开头时常用作说明字符串（docstring）；某些代码会读取 `__doc__` 作为命令行帮助。本次主要增加 `#` 注释，保持原说明字符串和逻辑不变。

## 从哪里开始读

建议先读完一个任务，再看另外两个任务的不同点。

1. `image_denoising/denoising_config.py`：先知道路径、图片尺寸、批次和轮数从哪里来。
2. `common/data.py` 与 `image_denoising/denoising_data.py`：观察一张图怎样变为“带噪输入、干净目标”。
3. `image_denoising/denoising_model.py`：跟着注释看图片尺寸怎样缩小又放大。
4. `common/engine.py`：理解前向计算、损失、求梯度、更新参数这四步。
5. `common/training.py` 与 `image_denoising/denoising_train.py`：理解怎样把前面的零件组装成完整训练流程。
6. 分类模块：比较“目标是类别整数”与“目标是整张图片”的区别。
7. 相似模块：先看编码器怎样得到 512 个特征，再读 `similarity_embeddings.py` 怎样保存与查询它们。
8. `common/inference.py`、`predict.py`：看训练后的参数怎样用于处理新图片。
9. `web/web_app.py` → `web/templates/index.html` → `web/static/app.js` → `web/static/style.css`：从后端请求处理读到前端显示。
10. `scripts` 和 `tests`：最后看怎样检查数据、评价模型、验证项目没有改坏。

每个文件可以分三遍：第一遍只读开头和函数说明；第二遍沿变量看输入输出；第三遍再读具体语句和语法。碰到公共函数时打开它的实现，读完再回到调用位置。

## 常见 Python 写法

```python
name = "cpu"                # 字符串，保存文字；= 是赋值
epochs = 30                 # 整数
learning_rate = 1e-3         # 浮点数，科学计数法，等于 0.001
enabled = True              # 布尔值，只有 True/False
result = None               # 暂时没有结果，不是数字 0，也不是空字符串
```

`==` 是比较两个值是否相等；`is None` 判断是否为表示“没有值”的那个特殊对象。`not` 取反，`and` 要两边都为真，`or` 在左边是假值时才取右边。`[]`、`{}` 等空容器在条件判断中通常为假。

| 写法 | 含义 |
|---|---|
| `[1, 2, 3]` | 列表，按顺序保存多项，可追加 |
| `(image, target)` | 元组，按顺序打包固定的一组对象 |
| `{"id": 15, "target": 2}` | 字典，通过键查值 |
| `{".jpg", ".png"}` | 集合，保存不重复项，适合做包含判断 |
| `items[0]` | 第一个元素，索引从 0 开始 |
| `items[-1]` | 最后一个元素 |
| `items[:4]` | 前四项，不包含索引 4 |
| `items[2:5]` | 索引 2、3、4 的项 |
| `mapping["id"]` | 用键查字典，没有该键会报错 |
| `mapping.get("id", 0)` | 查键，不存在则返回默认值 0 |
| `value += count` | 通常相当于 `value = value + count` |
| `a, b = function()` | 解包返回的两项，顺序必须对应 |
| `a, _ = function()` | 有意不用第二项；`_` 仍是普通变量名 |
| `a if condition else b` | 按条件选一项，只有选中的表达式会求值 |

列表推导式把简单循环写在一行：

```python
filenames = [path.name for path in paths]
# 对每个路径取 name，组成文件名列表。
# 等价思路是先建立空列表，再循环 append(path.name)。
```

`for a, b in zip(first, second)` 按位置把两个序列配对，较短的结束就停止。`enumerate(paths)` 每次返回“索引、路径”。`range(1, 4)` 产生 1、2、3，末尾的 4 不包含在内。

`*models` 把列表展开成位置参数，`**kwargs` 把字典展开成按名称传递的参数。例如 `f(*[1,2])` 相当于 `f(1,2)`，`f(**{"batch_size":4})` 相当于 `f(batch_size=4)`。它们与乘法的含义由所在位置区分。

`lambda x: decoder(encoder(x))` 是一个短函数，表示先编码、再解码。公共引擎把它当作可调用对象接收，所以同一套循环既能训练单模型，也能训练编码器和解码器。

`with Image.open(...) as image` 在块结束后自动关闭图片文件资源；`with torch.no_grad()` 是同样的语法，但管理的是梯度记录开关，不是文件。

`try/except` 用来处理可预期的失败；`raise` 主动报告错误。`finally` 无论成功还是失败都要执行，前端用它恢复按钮状态。

## 类、继承和 self

```python
class Example:
    def __init__(self, name):
        self.name = name     # 把信息放进这个对象，其他方法以后也能取用

    def show(self):
        return self.name

item = Example("商品")      # 创建对象时自动调用 __init__
text = item.show()           # 调用对象方法时，Python 自动把 item 作为 self 传进去
```

`class ImageDataset(ImageFolderDataset)` 表示继承：子类复用父类的读图能力，只改写加噪或返回标签的部分。`super().__init__(...)` 调用父类初始化。

特殊方法 `__len__` 对应 `len(dataset)`；`__getitem__` 对应 `dataset[idx]`。PyTorch 的 `nn.Module` 管理层和参数，外部写 `model(x)` 会经过框架调用机制执行 `forward(x)`，通常不应绕过它直接手动调用 `forward`。

`@torch.inference_mode()` 是装饰器，给整个方法应用推理计算设置。`@staticmethod` 不自动接收 `self`。`@classmethod` 自动接收类对象 `cls`，测试准备函数就使用它。

## 图片为什么能交给模型

图片由像素构成，RGB 每个像素有红绿蓝三个分量。普通图片常用 0～255 整数；这里先转成 0～1 浮点数，再组成 PyTorch 张量。

```text
一张 PIL 图片
  → Resize：统一为 64×64
  → ToTensor：[3,64,64]
  → DataLoader 取 4 张组成一批：[4,3,64,64]
```

形状 `[B,C,H,W]` 中：B 是批次张数，C 是通道，H 是高，W 是宽。最后一批可能不足批次上限，所以不能把 `B` 永远写死为 32。

`.shape` 查询形状；`.size(0)` 取第一维大小；`.ndim` 取维度数量。`.unsqueeze(0)` 加一个长度为 1 的轴；`.squeeze(-1)` 只在最后一轴为 1 时去掉该轴。`.flatten(1)` 保留批次轴，把后面的维度合并。

`.permute(1,2,0)` 把单图从 `[C,H,W]` 改为 `[H,W,C]`，以适合绘图。它不表示把颜色改成别的颜色。`.view(...)` 也不能随意放大图片，它要求元素总数一致；图像尺寸调整应使用专门的缩放操作。

`.to(device)` 移动计算设备；`.cpu()` 移回 CPU。`.detach()` 分离求导关系；`.numpy()` 把相应 CPU 张量转成 NumPy 数组供显示或数据库使用。

## 三个任务分别学什么

| 任务 | 输入 | 目标 | 模型输出 | 损失 |
|---|---|---|---|---|
| 去噪 | 带噪图片 | 干净原图 | `[B,3,64,64]` | MSE |
| 分类 | 商品图片 | 0～4 类别整数 | `[B,5]` 原始分数 | 交叉熵 |
| 相似表示训练 | 干净图片 | 同一干净图片 | 编码后 `[B,512]`，再解码重建 | MSE |

卷积学习局部图案；池化缩小高宽；转置卷积学习扩大空间尺寸；全连接层把多个特征组合成类别分数。通道数是学到的特征图数量，不总是图片的 RGB 颜色数量。

`ReLU(x)=max(0,x)` 增加非线性；`sigmoid` 把数值压到 `(0,1)`；`softmax` 把同一图片的五类分数变为总和为 1 的分数。模型置信度不是已经校准的正确概率。

## 训练的最重要几步

```python
optimizer.zero_grad()         # 清上一批的梯度
output = model(inputs)       # 前向运算，得到预测
loss = loss_fn(output, target)  # 量化“预测与目标相差多少”
loss.backward()              # 计算各参数的梯度
optimizer.step()             # 按优化器规则调整参数
```

学习率决定调整尺度，epoch 是遍历训练集的轮数，batch 是每次计算的一组图片。损失较低表示当前损失定义下差异较小，不保证所有实际应用指标都更好。

训练集用于更新参数；验证集用于比较效果和选择权重。项目保存的是验证损失最低的模型，不保证最后一轮就是最佳模型。`.train()`/`.eval()` 设置网络工作模式，`no_grad()` 控制是否记录反向梯度，这两组机制用途不同。

## 从向量到相似商品

编码器把每张图变成 512 个浮点数，即特征向量。建库与查询必须采用相同预处理和权重。代码对向量做 L2 归一化，Chroma 按余弦距离找相近记录。真实文件名同时被存成 id 和元数据，查回来后不需要猜“数据库第 5 条是不是 5.jpg”。

模型指纹用来识别是否同一套参数；它不是商品 id，也不是模型效果分数。`building/ready` 表示库是否完整写入。更换编码器或图片集合，需要按 README 重建对应索引。

## 网页怎样与 Python 配合

```text
index.html：页面有哪些按钮和图片区域
    ↓ 用户点击
app.js：读取文件、用 FormData + fetch 发 POST 请求
    ↓
web_app.py：路由读取 image 字段，交给 InferenceService
    ↓
模型处理，返回 JSON 或 Base64 图片文本
    ↓
app.js：更新 img.src、文本框和商品列表
style.css：始终负责这些元素怎样排列、显示多大、使用什么颜色
```

JavaScript `const` 不允许给同一个变量重新赋值，`let` 可以重新赋值；对象内容可否修改是另一个问题。`() => {...}` 是箭头函数。`async/await` 等待异步请求，不等于把浏览器整个界面锁死。项目用 `busy` 和 `disabled` 主动防止重复点击。

Python 返回的 JSON 会被 `response.json()` 解析成对象；HTTP 失败时 `fetch` 不一定自动抛异常，所以代码必须检查 `response.ok`。图片 Base64 是将二进制转成文本，不是模型特征向量。

HTML 的 `id` 通常唯一，`class` 可以由多个元素共用。CSS `.name` 匹配 class，`#name` 匹配 id，`:hover` 表示悬停。页面模板中的 `{{ url_for(...) }}` 由 Flask/Jinja 先处理，不是浏览器执行的 JavaScript。

## Notebook 与正式入口的区别

`apple.ipynb`、`denoising_test.ipynb` 是保留的历史实验。代码单元共享同一个内核里的变量，需要留意先执行了哪些单元；旧输出不一定是当前版本刚运行的结果。本次只增加代码注释，保留原输出和实验行为，没有重跑数百轮训练。

旧实验中存在已在注释指出的平均损失、固定批次 reshape 或变量命名问题。学习可以对照看；正式训练请使用各包的 `python -m ...` 入口，不要把旧实验代码复制回来替换已修正实现。

## 看懂以后怎样安全动手

先运行 `python -m unittest tests.test_project -v`，再用 README 的 `--epochs 1 --limit 16` 命令观察小样本流程，使用独立输出目录。先只调整轮数和批次大小，理解它们的影响后再尝试改变网络结构。

修改输入尺寸或网络通道后，需要一起检查下一层输入、展平维度、权重兼容和索引是否仍匹配。先修改一个因素、重新运行测试，比一次改动很多参数更容易看懂结果。
